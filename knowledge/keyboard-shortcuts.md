# Keyboard Shortcuts Reference

Essential After Effects keyboard shortcuts for efficient editing.

---

## Timeline Navigation

| Action | Mac | Windows |
|--------|-----|---------|
| Go to Beginning | `Home` | `Home` |
| Go to End | `End` | `End` |
| Go to Previous Frame | `Page Up` | `Page Up` |
| Go to Next Frame | `Page Down` | `Page Down` |
| Go Back 10 Frames | `Shift + Page Up` | `Shift + Page Up` |
| Go Forward 10 Frames | `Shift + Page Down` | `Shift + Page Down` |
| Go to Layer In Point | `I` | `I` |
| Go to Layer Out Point | `O` | `O` |
| Set Work Area Start | `B` | `B` |
| Set Work Area End | `N` | `N` |

## Layer Properties (Reveal)

Press these keys while layer is selected:

| Property | Shortcut |
|----------|----------|
| Anchor Point | `A` |
| Position | `P` |
| Scale | `S` |
| Rotation | `R` |
| Opacity | `T` |
| Audio Levels | `L` |
| Audio Waveform | `LL` (double tap) |
| Masks | `M` |
| Mask Feather | `F` |
| Effects | `E` |
| All Keyframed Properties | `U` |
| All Modified Properties | `UU` (double tap) |
| Expressions | `EE` (double tap) |
