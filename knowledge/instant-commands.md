# ⚡ Instant Commands

These commands execute immediately without AI API calls. Type them directly in the input field.

| Command | Action |
|---------|--------|

## 🎨 Effects (FX Console Style)

Type any effect name/alias to apply it instantly:

### Blur
- `blur` → Gaussian Blur
- `box blur` → Box Blur
- `fast blur` → Fast Blur
- `motion blur` → CC Force Motion Blur

### Color
- `curves` → Curves
- `levels` → Levels
- `hue` / `hue saturation` → Hue/Saturation
- `vibrance` → Vibrance
- `color balance` → Color Balance
- `exposure` → Exposure
- `tint` → Tint
- `tritone` → Tritone
- `colorama` → Colorama

### Stylize
- `glow` → Deep Glow / Glow
- `vignette` → CC Vignette
- `mosaic` → Mosaic
- `posterize` → Posterize
- `roughen edges` → Roughen Edges

### Generate
- `noise` / `fractal noise` → Fractal Noise
- `gradient ramp` → Gradient Ramp
- `4 color` / `4 color gradient` → 4-Color Gradient
- `checkerboard` → Checkerboard
- `grid` → Grid

### Distort
- `warp` / `bezier warp` → Bezier Warp
- `bulge` → Bulge
- `displacement` / `displacement map` → Displacement Map
- `liquify` → Liquify
- `mesh warp` → Mesh Warp
- `turbulent` / `turbulent displace` → Turbulent Displace

### Transition
- `linear wipe` → Linear Wipe
- `radial wipe` → Radial Wipe

### Keying
- `keylight` → Keylight
- `key cleaner` → Key Cleaner

### Audio
- `bass` / `bass and treble` → Bass & Treble
- `reverb` → Reverb
